# GS-OWL主方法图核对表

## 原图问题诊断

- 原图采用(a)(b)(c)大块分区，读者需要在多个局部图形之间来回寻找主线。
- 曲线、矩阵、公式框和长说明使用不同视觉语言，核心接口 `s_l` 不够突出。
- 分支连线存在回折，右侧汇合关系不直观；彩色版与黑白版的层级差异不足。
- 标题偏大而公式偏小，部分矩阵更像装饰，整体信息密度和留白分布不均衡。

## 新图信息结构

```text
OSLA  异常统计 -> OSLA层敏感性 -> 层预算 s_l -----------+
                                                        |-> 预算约束逐行剪枝 -> B_l,j 与 W~_l,j
GWS   权重与梯度 -> GWS显著性 -> 行内稳定排序 M^(l) ----+
```

## 图文、公式与含义核对

| 图中内容 | 论文定义或公式 | 位置 | 方法含义 |
|---|---|---|---|
| 异常统计 | `O_{l,j,r,c}=|W_{l,j,r,c}|sqrt(X_{l,j,c})` | 式(12)，`eq:outlier` | 由权重幅值和输入通道激活能量构造元素级异常得分。 |
| `c_l, v_l` | 异常比例见式(13)；严重度加权比例见式(14) | `eq:count`、`eq:severity` | `c_l`回答异常元素数量，`v_l`补充相对超阈幅度。 |
| OSLA层敏感性 | `d~_l=(1-alpha)d_l^c+alpha d_l^v` | 式(17)，`eq:fusion` | 以计数密度为锚点，用严重度密度进行有界修正。 |
| `C_dep -> Pi_s -> {s_l}` | 深度约束见式(18)，预算回投见式(19)，`s=1-d`见式(8) | `eq:depth_constraints`、`eq:budget`、`eq:framework` | 将候选保留密度约束并回投到全局预算，输出各层稀疏率。 |
| `W_{l,j}, G^(l)` | 聚合梯度 `G_{ij}^{(l)}=[sum_b(partial L_b/partial W_{ij}^{(l)})^2]^{1/2}` | 式(10)，`eq:gradient_aggregation` | GWS读取预训练权重和离线非负L2聚合梯度。 |
| GWS显著性 | `M_{ij}^{(l)}=|W_{ij}^{(l)}|sqrt(G_{ij}^{(l)})` | 式(11)，`eq:gws` | 平方根压缩梯度动态范围，得到连接保留优先级。 |
| 行内稳定排序 | `rank_up(M_{l,j,r,:})` | 式(7)前后的定义 | 在同一输出行内按显著性升序稳定排序。 |
| 行配额 | `q_{l,j}=floor(s_l d_{l,j}^{in})` | 式(7)前的行配额定义 | 将层稀疏预算转换为每个输出行的整数删除量。 |
| 二值掩码 | `B_{l,j,r,c}=I[rank_up(M_{l,j,r,c})>q_{l,j}]` | 式(7)，`eq:rowwise_mask` | 删除每行最低显著性连接，保留其余连接。 |
| 稀疏权重 | `W~_{l,j}=W_{l,j} odot B_{l,j}` | 第3.1节掩码定义 | 最终同时输出二值掩码和稀疏权重，保留权重不更新。 |

## 版式与输出核验

- 画幅：170 mm x 68 mm，横纵比2.50:1，按双栏通栏最终宽度直接设计。
- 路径区分：OSLA使用实线边框与圆形标记；GWS使用虚线边框与方形标记。
- 颜色：OSLA `#405B6D`，GWS `#875F5F`，汇合/输出 `#30343B`，背景纯白。
- 所有流程箭头均从左向右；无交叉线、回折线、渐变、阴影或面板编号。
- SVG文字和图形保持可编辑；PDF嵌入宋体与Times New Roman字形；PNG为白底600 dpi。
- 彩色、黑白和17 cm宽预览均已检查，未发现文字溢出、箭头交叉或模块重叠。
