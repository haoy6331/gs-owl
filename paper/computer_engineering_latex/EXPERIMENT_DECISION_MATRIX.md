| 实验 | 验证问题 | 处理建议 | 理由与风险 |
|---|---|---|---|
| 5个 LLaMA 模型 WikiText-2 PPL 主表 | 双尺度方法在不同模型、稀疏率下的语言建模质量 | 必须保留 | 直接支撑主结论；公开值与本地复现值必须继续分开标记 |
| PPL 趋势图 | 稀疏率升高时的退化趋势 | 必须保留 | 与主表互补，便于观察高稀疏率行为，不重复精确数值 |
| zero-shot 候选集合逐任务上界 | 候选掩码对不同任务的覆盖范围 | 建议保留为分析性副实验，或移入附录 | 与单掩码基线口径不同；不得作为公平 SOTA 比较 |
| Wanda/GWS × 均匀/OWL/OSLA 交叉消融 | 层间分配和层内排序的总体作用 | 必须保留 | 当前最直接的双创新归因证据 |

| 激活校准随机种子稳定性 | 激活采样波动 | 必须保留 | 标准差小，直接支持稳定性 |
| 校准样本数敏感性 | 精度与剪枝时间折中 | 必须保留 | 支持默认128样本设置；LLaMA-2-7B 的256样本点若缺失需说明 |
| Mistral-7B、Vicuna-7B 扩展 | 架构和微调模型迁移 | 必须保留 | 提供独立模型族证据；Mistral-7B 70%不优于 SparseGPT，应如实保留 |
| C4 固定配置迁移 | 评价语料变化后的退化规律 | 建议保留 | 没有同协议基线，只能说明配置迁移趋势 |
| 给定离线梯度后的剪枝时间 | 重复掩码生成开销 | 建议保留并弱化 | 不含梯度生成，不能称端到端效率或推理加速 |
| PLLaMA-7B/13B 植物科学选择题 | 专业领域模型的任务保持能力 | 建议保留为领域验证图 | 只比较 Dense 与 GS-OWL；必须注明每档20候选取最高值 |
| OSLA 五阶段内部消融 | 严重度、约束和回投的独立贡献 | 建议移入附录或不进入主论证 | 结果非单调，不能选择性写成“逐项均有效” |
| 参数网格热图 | 参数空间局部规律 | 建议移入附录 | 主文已包含梯度指数和样本敏感性，继续展示会分散主线 |
| Qwen2.5-7B 异常结果 | 中文/英文语料适配 | 暂不纳入正文 | 当前 PPL 与 zero-shot 异常，原因未定位，不能支撑方法结论 |
| OPT 系列结果 | 架构扩展 | 建议后续附录 | 当前主稿缺少统一基线与篇幅空间；不是核心论证必需 |

## 必须补充或确认

1. 找回或重跑 PLLaMA-7B Dense 结果 JSON。
2. 建立逐模型梯度生成元数据清单。
3. 填写作者、二级单位、基金、通信作者、代码地址和前3位作者联系方式；不适用项删除。
4. 明确匿名审稿要求，并保证投稿系统信息与 Word 稿完全一致。

## 强烈建议补充

1. 完整效率核算：梯度生成时间、梯度文件大小、峰值显存、重复剪枝时间。
2. OSLA 相对深度边界对照，或进一步弱化固定绝对层区间的泛化表述。
3. PLLaMA 固定掩码或独立验证集结果，以减少 best-of-20 选择偏差。
