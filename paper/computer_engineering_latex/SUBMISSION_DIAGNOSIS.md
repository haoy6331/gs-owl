# 《计算机工程》投稿适配与全文诊断报告

检查对象：`GS_OWL_计算机工程_官方模板投稿版.docx` 及其 LaTeX 源稿、参考文献、图表和实验说明。

研究方向：大语言模型训练后非结构化剪枝。

核心方法：GS-OWL，由异常严重度感知层分配（OSLA）与梯度加权显著性（GWS）构成。

## 1. 投稿适配结论

论文讨论大语言模型压缩、层间稀疏预算分配与连接级显著性排序，具有明确的算法问题和工程部署背景，与《计算机工程》的人工智能、模型压缩和高效计算选题方向匹配。全文已形成“问题定义—现有方法不足—双尺度方法设计—主实验—消融与稳定性验证—适用范围”的完整逻辑链。

稿件的可信定位是：在不更新保留权重的训练后剪枝条件下，通过层间预算与层内连接排序协同改善中高稀疏率下的掩码质量。正文未把非结构化参数稀疏率直接等同于通用 GPU 推理加速。

## 2. 投稿指南符合性

- 题目含14个汉字，另含方法缩写 GS-OWL，技术对象和核心机制明确。

- 中文关键词6个，均具有检索意义，未全部使用英文缩写。
- 中英文题目、摘要、关键词、图题、表题和中文参考文献译文已对应。
- 参考文献45条，正文首次引用顺序与文后著录顺序一致；中文文献均附英文译文。
- 正文含5幅图和7个编号表，均有中英文题名，并已在对象出现前由正文引用。
- 投稿 Word 版套用官方模板的页面、首页、标题层级、页眉页脚、题注和参考文献样式；统计图按黑白印刷要求输出。

## 3. 已具备的主要证据

1. WikiText-2 主实验覆盖5个 LLaMA 模型和50%--70%三档稀疏率，并扩展至 Mistral-7B、Vicuna-7B。
2. Wanda/GWS 与均匀分配/原始 OWL/OSLA 的交叉消融可区分层间预算和层内排序的总体作用。
3. 梯度指数、激活校准随机种子、校准样本数和 C4 固定配置迁移提供敏感性与稳健性证据。
4. PLLaMA-7B/13B 植物科学选择题实验补充领域模型任务保持能力分析。
5. 正文已明确 zero-shot 与 PLLaMA 为候选集合上界，C4 无同协议基线时不作优越性判断，13.9%仅表示给定离线梯度后的剪枝阶段开销。

## 4. A级问题：投稿前必须解决

### A1 作者和投稿信息仍未填写

Word 中保留19处“待填写”占位，包括作者、二级单位、省市邮编、基金、通信作者、CCF会员信息、代码地址、编辑部分配字段和前3位作者联系方式。投稿前必须按投稿系统信息逐项填写；无基金、CCF会员或代码链接时，应删除对应项目而不是保留占位符。

### A2 PLLaMA-7B Dense 原始记录需归档

PLLaMA-7B Dense 准确率39.823%（225/565）已有终端汇总依据，但结果目录中仍缺少对应的可机读 JSON。正式投稿归档前应找回或重跑 Dense 评测，并保存题目版本、提示模板和评分实现。

### A3 梯度生成元数据需统一核验

不同模型的离线梯度来自不同运行批次。应建立逐模型 manifest，核对语料、样本数、序列长度、批大小、聚合公式、缩放、数据类型和随机种子，使论文实验设置与实际文件一致。

### A4 投稿手续需由作者完成

需确认实名或匿名投稿要求，完成导师署名确认、单位保密审查、著作权转让及一稿多投声明，并保证投稿系统中的作者顺序和单位与 Word 完全一致。

## 5. B级问题：明显影响审稿可信度

1. OSLA 内部严重度、核心区约束、尾部限制和预算回投尚无完整的固定配置逐项消融；当前证据只能支持完整 OSLA 的总体作用。
2. PPL 主表取已评测有效配置中的最低值，zero-shot 和 PLLaMA 取候选集合上界。正文已区分口径，但仍建议归档搜索空间和配置选择规则。
3. 深度约束采用绝对层编号，跨更深或更浅架构的泛化证据不足；结论应限于所测32--40层模型。
4. 13.9%不含首次梯度生成、梯度存储与读取，也不是推理延迟或吞吐提升。
5. C4 表缺少同协议基线，仅能支持配置迁移趋势；不能据此声称跨语料优越性。
6. PLLaMA 每档为20个候选中的最高准确率，不能解释为预先固定单掩码的独立泛化性能。

## 6. C级与规范性问题

1. 中图分类号 `TP391.1` 需要作者结合最终技术定位确认。
2. 电子文献保留7个原始 URL，产生低等级可访问性提示，但符合电子文献著录需要。
3. Word 中公式为可编辑 OMML，而非 MathType OLE；需确认编辑部是否接受 Word 原生公式。
4. 第17页参考文献结束后的空白是自然尾页，不属于正文异常分页。
