# GS-OWL 论文润色说明与审稿风险清单

## 1. 与《计算机工程》的匹配度

综合匹配度：较高。

论文属于大语言模型压缩与训练后剪枝研究，包含明确的问题定义、算法设计、复杂度分析、主实验、消融实验和工程开销讨论，
与《计算机工程》关注的人工智能算法、模型优化和计算机工程应用方向相符。稿件采用中文科技论文体例，并按“目的—方法—结果—结论”
组织中英文摘要，具备面向中文计算机技术期刊投稿的基本结构。

当前稿件的主要优势是：

- 研究对象明确：大语言模型训练后非结构化剪枝；
- 方法结构清楚：OSLA 负责层间预算，GWS 负责层内连接排序；
- 模型和稀疏率覆盖较完整：5个 LLaMA 主模型、Mistral-7B，以及50%、60%、70%稀疏率；
- 已包含交叉消融、梯度指数、随机种子、校准样本数、跨架构和时间开销实验；
- 已明确非结构化参数稀疏不等同于通用硬件推理加速。

## 2. 本轮主要修改

### 题目与摘要

- 将题目调整为方法论文表达，突出大语言模型、双尺度敏感性和剪枝方法。
- 按“问题—不足—方法—量化结果—证据边界”重写中文摘要。
- 同步重写英文摘要，统一模型数量、稀疏率、PPL降幅、消融结论和13.9%时间开销。
- 关键词改为训练后非结构化剪枝、层间预算分配和连接显著性等可检索术语。

### 引言与相关工作

- 强化“部署成本—双尺度决策—现有方法不足—GS-OWL设计”的逻辑链条。
- 将层内剪枝、层间预算和梯度敏感信号按技术差异组织，减少文献罗列。
- 避免使用“首次”“普适”“证明”等超出证据范围的表述。

### 问题定义与方法

- 保留全部公式、符号和编号，统一“层间预算”和“层内连接排序”术语。
- 明确GWS是一阶扰动启发的排序代理，不是离散剪枝损失的精确估计。
- 明确OSLA固定深度区间是当前实现约束，不代表所有架构共享理论最优区间。
- 将复杂度部分改为“复杂度与工程边界”，区分掩码生成复杂度与实际推理加速。

### 实验与结论

- 将60%稀疏率结果改写为相对“最优同协议复现基线”的比较。
- 将70%层分配方法标明为论文公开参考值，不作为严格同协议比较。
- 将zero-shot表明确为候选掩码集合的任务级上界，不与单一掩码基线混同。
- 补充GWS在LLaMA-2-7B、70%稀疏率下未优于Wanda的适用范围说明。
- 明确Mistral-7B在70%稀疏率下低于Wanda但未超过SparseGPT。
- 将效率表统一改为“给定离线梯度后的掩码生成时间”，不再暗示推理加速。
- 重写讨论和结论，限制结论范围并删除重复、口语化和空泛表达。

## 3. 审稿风险清单

| 优先级 | 风险 | 当前状态 | 建议补强方式 |
|---|---|---|---|
| 高 | GS-OWL的PPL取有效配置中的最低值，但对比方法的搜索预算未说明是否相同 | 正文已说明结果选择口径，仍可能被质疑比较预算不对称 | 报告GS-OWL候选范围、选择规则和基线配置来源；最好补充统一搜索预算或固定配置结果 |
| 高 | zero-shot为不同任务分别选择最佳候选掩码后求均值，与单一掩码基线不同口径 | 正文和表注已明确为候选集合上界 | 增加由PPL确定的单一掩码zero-shot结果，作为严格同口径主比较；候选集合上界可保留为补充分析 |
| 高 | OSLA内部严重度、核心区约束、中后段约束和预算回投缺少逐项递进消融 | 现有交叉消融只能支持完整OSLA优于原始OWL | 增加“计数锚点 → +严重度 → +核心约束 → +中后段约束 → +预算回投”实验 |
| 高 | 效率实验未计入首次梯度生成、存储和读取成本 | 正文已限定为给定梯度后的重复掩码生成时间 | 单独报告梯度生成时间、梯度文件大小、峰值显存和复用次数下的摊销成本 |
| 中 | 未测量稀疏模型端到端推理吞吐和延迟 | 正文已明确不声称硬件加速 | 若论文需要突出工程效率，在支持非结构化、2:4或块稀疏的后端补充吞吐、延迟和峰值显存 |
| 中 | OSLA使用绝对层编号，主要覆盖32～40层解码器 | 已在方法和讨论中限定适用范围 | 增加相对深度版本，或在不同层数模型上验证保护区间迁移性 |
| 中 | 跨架构实验仅包含Mistral-7B，且70%稀疏率未超过SparseGPT | 正文已如实说明 | 增加OPT、Qwen或Vicuna等架构的同协议主表或消融结果 |
| 中 | 主PPL结果通常为单次有效运行，缺少重复试验误差 | 仅稳定性实验报告3个种子 | 对关键模型和稀疏率重复运行并报告均值、标准差或置信区间 |
| 中 | 软件版本、GPU显存、卡数和多卡映射策略未完整写入正文 | 当前仅列PyTorch、Transformers及GPU型号 | 增加可复现性表，列出版本、卡型、显存、卡数、精度、设备映射和随机种子 |
| 低 | 主表混合同协议结果与论文公开值 | 已使用符号和表注明确区分 | 投稿时可拆分为“同协议主表”和“公开层分配方法参考表”，进一步降低歧义 |
| 低 | 参考文献包含较新的2025—2026年工作 | 引用键和正文引用完整 | 投稿前逐条核对最终卷期、页码、会议名称和在线访问日期 |

## 4. 未修改内容

- 未改变任何实验结果、PPL、准确率、时间或稀疏率数值；
- 未改变公式的数学定义、编号和标签；
- 未增加虚构实验、基线、参考文献或方法机制；
- 未将TSP列为对比方法，也未提及其他论文的作者归属关系；
- 未声称非结构化稀疏能够直接带来通用GPU推理加速。
